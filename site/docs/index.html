Start with the working browser-only extension. Keep guides local, then export them or pair a compatible server. The v2 server targets and integrations are still being built; their status is listed below.

Install in this browser

Download a compiled extension. No Node.js, build tools or backend are needed to use it. Chrome and Edge use a side panel; Firefox uses a popup and full-tab editor. These are unsigned builds; store listings are not available yet.

  • Download compiled Chrome extension (.zip)
  • Download compiled Edge extension (.zip)
  • Download compiled Firefox extension (.zip)
  • Versions and SHA-256 checksums
  1. Download the ZIP for your browser and unzip it into a folder. The extracted folder contains manifest.json and the compiled app.
  2. In Chrome, open chrome://extensions, turn on Developer mode and choose Load unpacked. Select the extracted folder containing manifest.json.
  3. Open a web page and the StepDoc side panel. Choose This browser and start capture. Alt + Shift + S also starts or stops capture.
  4. Stop and review the steps, then save to the local editor. Export a PDF with Print / Save as PDF, a self-contained HTML file with embedded images and fonts, Markdown, DOCX, a portable .stepdoc bundle, guide.json, Playwright or SKILL.md. These exports run on your device without a backend, including while offline.

For Edge, load the extracted Edge folder from edge://extensions. For Firefox, load the compiled manifest as a temporary add-on from about:debugging. Store installation and signing are separate from these compiled builds.

Build from source (contributors)

Node.js and pnpm are needed only when compiling a new build yourself. 

git clone --branch main https://github.com/tanzir71/stepdoc.git
cd stepdoc
pnpm install --frozen-lockfile
pnpm build:extension

Compiled ZIPs are written to dist/ and site/downloads/.

Self-hosting targets

StepDoc v2 uses the same static app and Storage API across the following targets. The browser app and private pairing client work today. PHP/Cloudflare/Node Storage API v1 servers, passkey accounts and MCP services are in development; the commands shown on the landing page describe those target deployment paths.

Shared hosting — PHP + SQLite

Planned target: PHP 8.1+, a static app and a front controller. Keep the SQLite database and blob storage outside public_html. The installer and stepdoc-php.zip will ship with the PHP milestone; the archive is not available yet.

Cloudflare — Workers + D1 + R2

Planned target: a Worker serves the same API, with D1 metadata and R2 images. Local Wrangler verification and a deployment configuration are part of the Cloudflare milestone. The v2 Worker is not available to deploy yet.

Node + Postgres

The existing v1 Next.js/Supabase app remains in the repository. The v2 target will serve the static app and Storage API v1. Keep the v1 editor/API private; it is a single-user internal tool without account authentication. Read the repository setup instructions before running it.

Guides for people and browser agents

Current exports include guide@1 JSON, Markdown, Playwright and SKILL.md. Targets carry accessible roles and names, with selectors as fallbacks. Fill steps reference variables or secrets; replay values are supplied at runtime. The generated replay has automated local-browser coverage. MCP servers and WebMCP registration are planned integrations.
