# Deploy the StepDoc public website

Vercel serves only `site/`. It does not deploy the private editor/API, extension, Supabase credentials, or user data.

Run `pnpm website:guide` before deployment so `/demo/` is regenerated by the production HTML-export renderer, then run `pnpm website:verify` and deploy with `vercel --prod --yes`.

The main StepDoc app is a single-user internal tool without authentication and must not be exposed publicly. Only read-only published guide routes are intended for sharing.
